# VidoraX

A free, static, browser-based video downloader starter site.

## Run locally
Open `index.html` in a modern browser.

## Publish free with GitHub Pages
1. Create a GitHub account and a new public repository.
2. Upload `index.html`.
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub Pages will provide a public website address after deployment.

You can also deploy the folder using another static hosting provider with a free tier.

## Important limitations
This is a static front-end, not a universal downloader. It downloads direct video-file URLs only when the host permits browser `fetch` access (CORS). Ordinary watch-page URLs from video platforms generally will not work. Do not bypass DRM, paywalls, logins, age checks, download restrictions, or other access controls. Use only content you own or are authorized to download and comply with each source's terms and applicable law.

No video is uploaded to a VidoraX server by this page. There is no backend, database, analytics, or account system.
